DEIN LESESTOFF HAT EIN ZUHAUSE

Verbinde deinen Server.

Ein guter Artikel muss kein offener Tab bleiben. Sende ihn an redread und höre ihn später in deinem Podcastclient.

Gib die vollständige Adresse mit Port ein, ohne zusätzlichen Pfad. Dein Browser muss den Server erreichen können – bei Tailscale muss die Verbindung aktiv sein.

Du entscheidest, was deinen Browser verlässt.

Erst beim Klick auf „Artikel hörbar machen“ werden Titel, URL und lesbarer Artikeltext an deinen Server übertragen. Auch angemeldete Inhalte können dabei enthalten sein. Dein Server verarbeitet den Text mit den dort konfigurierten LLM- und TTS-Anbietern.

Keine automatische Sammlung, keine Analytics und keine API-Keys in der Erweiterung. Die Adresse wird nur lokal in diesem Browser gespeichert.
